# Версии приложения и Rust

Приложение следует SemVer. Сейчас версии приложения нет; первая версия реально
работающего CLI планируется как `0.1.0`. Не создавать файл версии или тег Git
до приложения. GitHub Release — отдельная явно порученная операция.

При появлении Cargo-проекта единственный источник версии приложения — `package.version`
корневого `Cargo.toml`; если реальная архитектура потребует workspace —
`workspace.package.version` с наследованием участниками. Выбрать один вариант,
обновить этот контракт; CLI и метаданные получают версию из Cargo, без ручных копий.

В каждой задаче, меняющей поведение, сверить источник версии со свежей `origin/main`,
оценить необходимость повышения версии и включить решение и изменение в PR. Исправление ошибки
требует patch, новая совместимая возможность — minor, несовместимость стабильного
публичного контракта — major. До `1.0.0` несовместимые изменения повышают minor
с явным описанием миграции. Чистая документация и инфраструктура без изменения
поведения приложения сами по себе повышения версии не требуют. Не повышать версию механически
повторно, если текущий PR уже содержит нужное повышение относительно main.

## Toolchain и MSRV

Сейчас единственная версия Rust закреплена в `rust-toolchain.toml`; MSRV ещё нет.
Использовать только опубликованные стабильные версии, без beta/nightly.

При первом манифесте Cargo объявить каноническую MSRV в `package.rust-version`
либо в `workspace.package.rust-version` с наследованием — по фактической структуре.
Для этого проекта закреплённый toolchain и MSRV должны соответствовать одному
стабильному релизу Rust; хранить полный номер `X.Y.Z`. В той же задаче настроить
Renovate на совместное обновление обоих источников через источник данных `rust-version`,
проверив актуальные возможности менеджера Cargo и фактическое извлечение версий.
Пользовательский менеджер допустим только если встроенного недостаточно и он ограничен
каноническим полем фактического манифеста. Сейчас менеджера регулярных выражений нет, поскольку
нет файла, к которому он применим. Простая группировка PR не доказывает синхронность
двух значений; это отдельная проверка при изменении Rust.
