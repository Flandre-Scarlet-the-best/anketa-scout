# anketa-scout
Кроссплатформенный инструмент для поиска, сбора и фильтрации анкет с имиджбордов, форумов и других площадок с возможностью расширения списка источников.

Проект находится на стадии архитектурной и инфраструктурной подготовки.
Прикладного кода, Cargo-проекта, исполняемого CLI/TUI, тестов и CI/CD пока нет.
Планируемая реализация — Rust для Windows, Linux и macOS; первым интерфейсом будет CLI.

Анкета — сообщение с хотя бы одним собственным контактом автора. Отсутствие возраста,
пола, города или фотографии само по себе не исключает анкету; цитата чужого контакта
сама по себе не доказывает её наличие.

Для разработки начните с [AGENTS.md](AGENTS.md) и
[карты постоянного контекста](.codex/context/INDEX.md). Там находятся владельцы
архитектурных решений, правил разработки, проверки и версионирования, а также
процедуры Git/GitHub и ревью для Codex и Claude Code.
