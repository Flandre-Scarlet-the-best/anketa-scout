# Anketa Scout: инструкции агентам

Anketa Scout — будущий кроссплатформенный инструмент работы с анкетами. Сейчас
репозиторий содержит инфраструктуру и контракты; приложения и Cargo-проекта нет.

## Глобальные инварианты

- Общение, собственная документация, комментарии, пользовательские сообщения,
  логи и описания PR — на русском. В Conventional Commits тип и scope остаются
  английскими, описание после двоеточия — русским. Идентификаторы, API и машинные
  контракты не переводить. Применять это к создаваемому и изменяемому материалу.
- Прикладная реализация — только Rust. Не добавлять shell-скрипты и обёртки
  Bash/SH, PowerShell, Batch/CMD; нетривиальная автоматизация при необходимости
  также пишется на Rust. Не создавать заготовки автоматизации заранее.
- Сохранять чужие изменения; менять только область задачи. Утверждения о текущем
  состоянии проверять по файлам и Git, внешние изменяемые сведения — по первичным источникам.

## Маршрутизация

Перед работой прочитать [индекс владельцев](.codex/context/INDEX.md), затем только
относящиеся к задаче документы. Правило изменяется у своего канонического владельца,
а в остальных местах остаётся ссылка. Контекст — долговременные решения, не журнал
агента, PR или разового прогона.

Skills Codex находятся в `.agents/skills/`; входы Claude Code — в `.claude/skills/`.
Процедуру Git/GitHub определяет `scout-git-workflow`, независимое ревью —
`scout-code-review`, явно порученный CodeRabbit — `scout-coderabbit-review`.
Порядок подключения и смысловая маршрутизация описаны в индексе.
