# Явное ревью CodeRabbit

## Активация

Запускать **только** по положительному поручению пользователя именно запустить CodeRabbit. Упоминание в документации, PR, обычное «сделай ревью», правка skill, наличие CLI или желание «быстрее проверить» не являются разрешением. Не устанавливать сервис, не менять настройки GitHub, не обновлять CLI, не отправлять приватные данные побочным эффектом.

Codex/Claude вызывают каноническую процедуру явно согласно [индексу](../../../.codex/context/INDEX.md). Ограничения неявной активации сохраняются в метаданных, но не заменяют запрет побочных эффектов.

## Владение и инварианты

- Skill отвечает за **процедуру внешнего ревью**: выбор candidate/base, фактический запуск, подтверждённое завершение, triage, ограничение итераций и передаваемую публикации таблицу.
- Git/GitHub commit/push/PR выполняет **[scout-git-workflow](../scout-git-workflow/SKILL.md)**. Набор проверок выбирает [VERIFICATION.md](../../../.codex/context/VERIFICATION.md).
- По умолчанию выполнять **3 завершённые итерации**, если пользователь не задал иное положительное количество. Чистый проход без исправлений — **не** разрешение досрочно завершить оставшиеся; отдельные отказ/недоступность останавливают с честным статусом.
- Каждая завершённая итерация относится к точному опубликованному HEAD и включает независимую оценку каждого замечания, применимые проверки, commit/push, подтверждение удалённого SHA и обновление накопительной таблицы текущего PR. Если реальных исправлений нет — допустим пустой смысловой commit для фиксирования завершённой итерации, **только после настоящего завершённого ревью**.
- Skip, неправильная база, лимит запросов, обрыв, ошибка CLI, частичный результат, слишком большой scope или неопределённое завершение **не** расходуют завершённую итерацию.
- Deep review — только если пользователь запросил; не заменять недоступный режим другим молча.
- Не менять проверяемый PR, ветку или scope самовольно, не уничтожать чужие изменения; не делать merge, force-push и Release.
- CodeRabbit — консультирующий рецензент. Каждую находку проверять по исходникам и тестам; нельзя принимать автоматически или скрывать отклонённые с объяснением.

## Подробная процедура

**До запуска** прочитать [review-workflow.md](references/review-workflow.md). Там единственный контракт discovery текущего интерфейса CLI, выбора режима/base, распознавания полного результата, triage, чистой итерации, rate limit и обновления PR.

Незавершённость и ограничения передавать отдельно от количества «прошедших» итераций. Наличие замечаний само по себе не доказывает завершение ревью.
